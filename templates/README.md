# Templates

Halaman full hasil rakitan dari `components/` + `animations/`. Ini titik mulai paling cepat untuk
project klien baru — copy filenya, find-replace `[BrandName]` / `[Tagline]` / warna, isi konten asli.

| File | Cocok untuk |
|---|---|
| `landing-page-template.html` | Company profile / landing page 1 halaman — basis untuk Paket 1 (Statis) |

Semua template sudah include AOS (lihat `animations/README.md`) dan Tailwind CDN, jadi tinggal buka
di browser langsung tanpa build step.
