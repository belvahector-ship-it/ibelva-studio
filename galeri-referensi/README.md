# Galeri Referensi Desain

Tiga contoh gaya UI (SaaS terang, portfolio gelap, dashboard healthcare) yang dipakai sebagai bahan
diskusi arah desain dengan calon klien — **bukan hasil kerja iBelva Studio**.

## Sumber & Lisensi

Diambil dari [`nextlevelbuilder/ui-ux-pro-max-skill`](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
(folder `projects/`), dipakai di bawah [Lisensi MIT](LICENSE-ui-ux-pro-max-skill.txt) — bebas dipakai,
dimodifikasi, dan didistribusikan ulang termasuk untuk keperluan komersial, selama notice lisensinya
tetap disertakan (sudah ada di folder ini).

Tiap file HTML di sini juga diberi komentar atribusi di baris atas + banner kecil "Referensi gaya —
bukan portofolio klien iBelva Studio" supaya pengunjung situs tidak salah kira ini project klien asli.

## Kenapa Dipajang

Katalog `components/` dan `templates/` kita masih kecil. Galeri ini bantu calon klien menunjuk arah
("aku mau yang kayak gini") sebelum project dimulai, sambil komponen kita sendiri terus bertambah
lewat [sistem katalog organik](../docs/katalog-organik.md).

## Isi

| Folder | Gaya |
|---|---|
| `saas-landing/` | Terang, biru-oranye, ramah — cocok produk/layanan approachable |
| `portfolio-dark/` | Gelap, editorial, personal — cocok portofolio/brand eksklusif |
| `healthcare-dashboard/` | Bersih, data-heavy, tenang — cocok admin panel/dashboard |

Buka [`index.html`](index.html) untuk hub-nya.
